核心功能

专为高效知识库构建设计，六大核心功能让文档管理化繁为简

批量上传

自动遍历指定目录及其所有子目录，递归发现并逐个上传文档到 RAGFlow 知识库，无需手动分批。支持 .md、.txt、.pdf、.docx 等多种格式。

自动解析

上传后自动触发文档切片和解析，无需手动点击"解析"按钮。可配置仅上传不解析，或上传后自动解析并监控进度。

实时进度监控

实时监控每个文档的解析进度，可配置解析进度查询间隔、首次解析等待时间，全程透明可控。

元数据管理

支持为每个文档设置自定义元数据（作者、分类、标签、版本等），只需创建同名 .meta.json 文件即可，让知识库检索更精准。

断点续传

自动记录每个文件的处理状态（待处理 / 已上传 / 解析中 / 完成 / 失败），中断后重新运行会自动跳过已完成的文件，仅继续处理未完成或失败的文件。

纯 API / SDK 模式

无需数据库依赖，完全基于 RAGFlow API / SDK 运行，部署简单，配置即用。既可源码运行，也可下载开箱即用的桌面客户端。

3 步快速开始

简单三步，即可搭建高效的知识库管理流程

1

安装配置

下载客户端或克隆源码，完成安装与配置。桌面客户端零代码启动，源码运行支持 Python 3.13+。

2

获取密钥

在 RAGFlow 中创建知识库，获取 API Key（用户头像 → API → 创建新密钥）。

3

运行工具

配置文档目录、支持的文件后缀、分块方法，点击运行——工具自动遍历、上传、解析，全程进度可见。

方式一：桌面客户端（推荐）

在 GitHub Releases 页面下载编译好的客户端（Windows / macOS / Linux），启动后在图形界面填写 API 地址、密钥、知识库信息，点击"运行"即可。零代码、零配置文件。

前往下载

方式二：源码运行

克隆仓库，创建 Python 3.13+ 虚拟环境，安装依赖，复制并编辑配置文件，一行命令启动：

$ python -m ragflows.main
